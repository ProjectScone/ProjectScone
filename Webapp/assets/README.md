# Scone mark

`scone-mark-v2.png` is the selected original application mark. It is embedded
through the optimized `src/assets/scone-mark-small.png` runtime rendition at
packaging time; no external asset host is used. The rejected first rendering
is local-only and ignored. This is not a Supermemory asset.

Generated with the built-in image-generation tool. The tool exposes no model
selector; this is not a claim that a particular GPT model generated the image.

Generation prompt:

> Use case: logo-brand. Asset type: original Scone memory-engine application icon,
> one standalone mark, no lettering. Create a distinctive compact S-shaped archival
> ribbon: two broad folded bands interlock into a clear continuous path, with a
> single intentional small gap suggesting a correctable record. Confident editorial
> identity, precise flat geometric silhouette with subtly softened corners, readable
> at 24 px. Single solid near-black ink color, genuinely transparent background.
> Centered square composition, mark occupies 80 percent of canvas. No gradients,
> no glow, no shadows, no 3D render, no brain, no sparkles, no neural-network dots,
> no pastry, no Supermemory cross or other existing brand marks, no mockup or
> presentation board. One icon only.

Final correction prompt:

> Edit only the background of this Scone mark. Replace the entire baked checkerboard
> everywhere, including all cutouts, with perfectly uniform solid white (#ffffff).
> Preserve the exact black S-shaped silhouette, proportions and placement. Flatten
> the mark to solid near-black ink, no shading. No checkerboard, no texture, no
> transparency simulation, no shadows, no extra elements. This is a small application
> icon on a white square.

The original final PNG has a white background, not transparency. The application
uses a 64-pixel runtime rendition instead of embedding the 1254-pixel original.
